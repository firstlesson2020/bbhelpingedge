# BB Helping Edge

A small static landing page inspired by the values of Bhagat Singh and dedicated to practical community upliftment.

## Project structure

- `index.html` — page content and layout
- `styles.css` — styling and responsive design
- `script.js` — simple count-up animation and footer year
- `assets/` — SVG assets for branding and donation QR placeholder

## Run locally

Open `index.html` directly in a browser, or serve the folder with a simple local web server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
